# ICON CAFE 발표용 시연 웹앱

고객 홍보 페이지, 쿠폰 발급·표시, 직원 쿠폰 확인·사용, 관리자 편집 화면을 **한 브라우저에서 시연**할 수 있는 로컬 웹앱입니다. 별도 설치나 Supabase 계정 없이 실행됩니다.

> **발표용 데모입니다.** 쿠폰·로그인·관리자 권한·통계는 브라우저 저장소에서만 동작합니다. 실제 매장 쿠폰으로 사용하거나 인터넷에 공개 운영하면 안 됩니다. 실제 운영 기능의 기준은 [PRD.md](PRD.md)를 참고하세요.

## 실행

Windows PowerShell에서 이 폴더를 연 뒤 실행합니다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\serve.ps1
```

브라우저에서 **http://localhost:4173/** 를 엽니다. **PowerShell 창을 열어 둔 동안만 홈페이지가 보입니다.** 창을 닫았거나 연결 오류 화면이 남아 있으면 서버를 다시 실행하고 브라우저를 새로고침하세요. Codex 인앱 브라우저에서 연결 오류가 계속되면 일반 Chrome 또는 Edge에서 같은 주소를 여세요. 종료할 때는 실행 중인 PowerShell 창에서 `Ctrl+C`를 누릅니다. 다른 포트를 쓰려면 `-Port 4200`처럼 지정할 수 있습니다.

`index.html`을 파일로 직접 열 수도 있지만, 카메라 권한과 경로 처리 때문에 localhost 실행을 권장합니다. Chrome 또는 Edge의 최신 버전에서 시연하세요. 카메라 인식이 지원되지 않거나 권한이 없으면 직원 화면에서 쿠폰 번호를 직접 입력할 수 있습니다.

## 3분 시연 순서

1. 고객 화면의 **무료 아메리카노 쿠폰 받기**를 누릅니다. Code128 바코드와 쿠폰 번호가 표시됩니다.
2. 쿠폰 번호를 복사하거나 화면을 켜 둔 채 **직원 화면**을 새 탭에서 엽니다. **직원 화면 시작하기**를 누릅니다.
3. 번호를 입력하고 **코드 조회**를 누릅니다. 첫 방문과 케이크 구매 체크박스를 선택한 뒤 **사용 확정**을 누릅니다.
4. 고객 화면의 **내 쿠폰 보기**를 다시 열면 `사용완료`가 표시됩니다.
5. **관리자 시연**에 들어가 통계를 확인하고 메뉴 가격·품절·홍보 문구·행사 설정을 바꿉니다. 고객 화면을 새로고침하면 변경 내용이 반영됩니다.

같은 브라우저의 일반 탭에서 시연하세요. 시크릿 창, 다른 브라우저, 다른 기기는 저장소를 공유하지 않습니다. 관리자 대시보드의 **시연 데이터 초기화**로 초기 상태로 돌아갈 수 있습니다.

## 화면과 데이터

| 경로 | 기능 |
|---|---|
| `/` | 반응형 홍보 페이지, 메뉴 9종, 쿠폰 발급·재표시 |
| `/staff/` | 발표용 원클릭 입장, Code128 카메라 스캔 또는 수동 입력, 사용 확정 |
| `/admin/` | 발표용 원클릭 입장, 메뉴·콘텐츠·행사 편집, 쿠폰 통계·내역 |

가격과 메뉴 설명은 `app.js`의 `seed()` 함수에 있습니다. 장소는 계원예술대학교 평생교육원 구내카페로 표시하고, 지도는 평생교육원 위치를 가리킵니다. 구내카페의 정확한 건물·층과 영업시간은 아직 확인되지 않았습니다. 화면의 9개 음식·음료 사진은 AI가 만든 **가상 콘셉트 이미지**입니다. 최적화된 JPEG는 `assets/`에 있으며 원본 PNG도 같은 폴더에 보관했습니다. 관리자 화면에서 메뉴 이미지를 업로드해 이 브라우저의 시연 데이터로 교체할 수 있습니다. 사진은 640px JPEG로 축소해 저장합니다.

당근케이크 소개 영역에는 제공받은 비교 HTML을 바탕으로 스케치와 완성 콘셉트를 겹쳐 보는 슬라이더를 적용했습니다. 화면에 들어오면 한 번 전환되며, 마우스·터치 드래그, 키보드 방향키, 범위 조절 막대와 선택 버튼으로 비교할 수 있습니다. 움직임 줄이기 설정에서는 자동 전환을 생략합니다.

## 구현 범위와 한계

- 쿠폰은 발급 시각부터 기본 168시간 유효하고, 같은 브라우저에서는 기존 쿠폰을 다시 표시합니다. 사용완료·만료 후 자동 재발급하지 않습니다.
- 스캔만으로 쿠폰은 사용되지 않습니다. 직원 화면에서 두 확인 항목을 선택하고 **사용 확정**을 눌러야 상태가 변경됩니다.
- 행사 중지 또는 당근케이크 품절 시 신규 발급이 중지됩니다. 이미 발급한 쿠폰은 원래 만료 시각까지 표시됩니다.
- 데이터는 `localStorage`에 저장됩니다. 브라우저 데이터를 지우면 쿠폰과 관리자 수정 내용이 사라집니다. 서버 시각·실제 권한·동시 사용 원자성·기기 간 공유는 제공하지 않습니다.
- 발표용 원클릭 입장은 실제 인증이 아닙니다. 실제 운영 전 Supabase Auth, RLS, 서버 발급·조회·검증 API, 원자적 사용 처리, 속도 제한과 감사 기록을 구현해야 합니다.
- 원산지·유기농·무가당·알레르기·실제 판매 가격과 매장 정보는 확인되지 않았습니다. 해당 표현과 이미지는 발표용 가상 콘텐츠로만 취급하세요.

## 파일

- `PRD.md`: 향후 실제 운영 개발의 기준 문서
- `PLAN.md`: 발표용 구현 계획과 운영 전 전환 사항
- `index.html`, `staff/index.html`, `admin/index.html`: 화면 진입점
- `app.js`: 시연 데이터와 화면 동작
- `styles.css`: 반응형 디자인
- `serve.ps1`: localhost 정적 파일 서버
- `assets/*.jpg`: 최적화한 AI 콘셉트 이미지
- `assets/cake-before.webp`, `assets/cake-after.webp`: 첨부 HTML에서 분리한 비교용 콘셉트 이미지
- `assets/favicon.svg`: 아이콘카페 파비콘
- `assets/og-card.png`: 1200×630 공유 미리보기 이미지 (`og-card-source.png`는 원본)
- `assets/jsbarcode.min.js`: [JsBarcode 3.11.6](https://github.com/lindell/JsBarcode), MIT 라이선스, Code128 렌더링용

## 발표 후 실제 운영으로 전환할 때 필요한 자료

실제 메뉴·가격·판매 여부, 구내카페의 정확한 건물·층과 영업시간, 실물 사진, 제주 구좌산 및 유기농 증빙, 확정 레시피와 알레르기 정보, 쿠폰 운영·개인정보 정책이 필요합니다. Supabase 프로젝트와 직원 계정도 그 단계에서 준비합니다.
